# ⚡ Digital Hardware Design & Architectures (VHDL)

> A modular repository containing clean, synthesizable **VHDL** implementations of fundamental and intermediate digital logic systems, combinational building blocks, sequential elements, and state machines.

---

## 📂 Architecture & Directory Layout

The repository is structured logically by digital design categories to maintain clean separation of concerns:

```text
Digital-Hardware-Design-VHDL/
├── Combinational/       # Adders, Subtractors, Multiplexers, Encoders/Decoders
├── Sequential/          # Latches, Flip-Flops, Counters, Shift Registers
├── Arithmetic-Logic/    # ALUs, Comparators, Multipliers
├── FSM/                 # Mealy and Moore Finite State Machine implementations
└── README.md
